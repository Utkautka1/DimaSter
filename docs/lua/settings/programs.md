# Управляющие последовательности

[← к оглавлению](../README.md)

Что программы могут делать с DimaSter. Список повторяет разделы справочника Ghostty.

## Что можно запретить

```lua
return {
  programs = {
    title = true,         -- OSC 0, 2
    colors = true,        -- OSC 4, 5, 10–19
    cursor_shape = true,  -- DECSCUSR
    pointer_shape = true, -- OSC 22
    progress = true,      -- OSC 9;4
    notifications = true, -- OSC 9, 777
    shift_mouse = true,   -- XTSHIFTESCAPE
  },
  bell = {
    flash = true,         -- вспышка рамки
    color = "#e0af68",
    attention = true,     -- просить внимания, если окно не в фокусе
    notify = false,
    command = {},         -- например { "paplay", "/путь/к/звуку.oga" }
  },
}
```

Запись в буфер обмена (OSC 52) отключается ключом `clipboard_write`, чтение буфера программами не поддерживается никогда. Плагины получают событие `bell`.

## Управляющие символы

| | Действие |
|---|---|
| `BEL` | звонок, см. `bell` |
| `BS`, `CR`, `LF`, `TAB` | назад, в начало строки (или к левому полю), вниз, табуляция |

## ESC

| Последовательность | Действие |
|---|---|
| `ESC # 8` (DECALN) | заполнить экран буквами E |
| `ESC =`, `ESC >` (DECKPAM, DECKPNM) | цифровой блок: режим приложения и обычный |
| `ESC 7`, `ESC 8` (DECSC, DECRC) | сохранить и вернуть курсор |
| `ESC D`, `ESC M`, `ESC E` (IND, RI, NEL) | вниз, вверх с прокруткой, новая строка |
| `ESC c` (RIS) | полный сброс |

## CSI

| Последовательности | Действие |
|---|---|
| `A B C D E F G H` (CUU…CUP), `` ` `` `a d e` (HPA, HPR, VPA, VPR) | перемещение курсора |
| `I`, `Z`, `g` (CHT, CBT, TBC) | табуляция |
| `J`, `K`, `X` (ED, EL, ECH) | стирание |
| `@`, `P`, `L`, `M` (ICH, DCH, IL, DL) | вставка и удаление |
| `S`, `T`, `b` (SU, SD, REP) | прокрутка и повтор |
| `r` (DECSTBM) | верхнее и нижнее поля |
| `?69h` + `s` (DECSLRM) | левое и правое поля; без режима 69 `CSI s` сохраняет курсор |
| `SP q` (DECSCUSR) | форма курсора |
| `n` (DSR) | состояние и позиция курсора |
| `> Ps s` (XTSHIFTESCAPE) | Shift с мышью достаётся программе |

## OSC

| Код | Действие |
|---|---|
| 0, 2 | заголовок окна; 1 (значок) принимается и не показывается |
| 4, 104 | палитра: изменить, спросить, сбросить |
| 5, 105 | особые цвета; на вид влияет только 0 — жирный текст |
| 7 | текущий каталог |
| 8 | гиперссылки |
| 9, 777 | уведомление |
| 9;2, 9;4, 9;9 | расширения ConEmu: сообщение, ход выполнения (полоска и `info.progress`), каталог. Остальные номера игнорируются: паузы и заголовки вкладок Windows не исполняются |
| 10–19, 110–119 | цвета текста, фона, курсора, выделения (17, 19); 13–16 и 18 запоминаются и отвечают на запрос, на вид не влияют |
| 22 | форма указателя (имена CSS: `text`, `pointer`, `crosshair`, `wait`…) |
| 52 | запись в буфер обмена |
| 104, 133, 633, 1337 | сброс палитры, метки shell, картинки iTerm2 |

## Когда что отключать

| Мешает | Настройка |
|---|---|
| заголовок окна постоянно меняется | `programs.title = false` |
| программа перекрасила терминал и не вернула цвета | `programs.colors = false`, разово — команда `reset` |
| редактор меняет форму вашего курсора | `programs.cursor_shape = false` |
| слишком много уведомлений | `programs.notifications = false` |
| мышь с Shift не выделяет текст в программе | `programs.shift_mouse = false` |

## Проверить из shell

```bash
printf '\a'
```

```bash
printf '\e]9;4;1;60\a'
```

```bash
printf '\e]9;4;0\a'
```

Первая команда звонит, вторая показывает полоску выполнения на 60 %, третья убирает её.

## Звук вместо вспышки

```lua
return {
  bell = { flash = false, command = { "paplay", "/usr/share/sounds/freedesktop/stereo/bell.oga" } },
}
```

Программа запускается напрямую, без shell: аргументы перечисляются по отдельности. Чаще раза в 300 мс звонок не повторяется.
