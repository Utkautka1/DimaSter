# Внешний вид

[← к оглавлению](../README.md)

| Ключ | Тип и значения | По умолчанию |
|---|---|---|
| `theme` | имя темы | нет |
| `colors` | таблица цветов поверх темы (см. [Темы](../themes/themes.md)) | нет |
| `padding` | число или `{ x = , y = }`, пиксели, 0–500 | `{ x = 25, y = 20 }` |
| `minimum_contrast` | минимальный контраст текста к фону, 1.0–21.0 | `1.0` |
| `cursor` | `"block"`, `"underline"`, `"bar"` или таблица — см. [Курсор](../interface/cursor.md) | `"bar"` |

## Отступы

```lua
return { padding = 12 }                      -- одинаково со всех сторон
```

```lua
return { padding = { x = 25, y = 20 } }      -- по горизонтали и вертикали
```

## Цвета поверх темы

```lua
return {
  theme = "nord",
  colors = { background = "#101010", cursor = "#ff79c6", selection = "#44475a" },
}
```

Ключи те же, что в файле темы: `foreground`, `background`, `cursor`, `selection`, `selection_text`, `ansi`.

## Контраст

```lua
return { minimum_contrast = 4.5 }
```

Текст, сливающийся с фоном, осветляется или затемняется до заданного отношения яркости. `1.0` — не вмешиваться, `4.5` — удобно читать, `21.0` — только чёрное и белое.

Прозрачность и фоновая картинка — на странице [Окно](window.md).
