# Защитные пределы и внутренние значения: `limits`

[← к оглавлению](../README.md)

> **Осторожно.** Это то, что защищает терминал от зависания и переполнения памяти, и то, на что рассчитана отрисовка. Увеличив предел, вы снимаете защиту. Менять `limits` могут не только ваши файлы, но и **любой плагин** (`dimaster.set`).

Задавайте только то, что нужно изменить:

```lua
-- local.lua
return {
  limits = {
    clipboard_bytes = 4 * 1024 * 1024,  -- в Lua можно считать
    plugin_budget_ms = 300,
  },
}
```

## Правила

- Значения — целые неотрицательные числа. Единицы видны из имени и описания: `_bytes` — байты, `_ms` — миллисекунды, `_secs` — секунды, `_px` — пиксели, `_percent` — проценты.
- **Неизвестное имя — ошибка конфига**: терминал запустится с настройками по умолчанию и напечатает `limits.<имя>: ?`.
- Значение за пределами столбцов «минимум» и «максимум» молча приводится к ближайшей границе: за ними код упал бы.
- Слои объединяются по ключам: `local.lua` перекрывает только названные пределы.
- Убрали ключ — после перечитывания вернётся стандартное значение.
- Пределы общие для всего процесса.
- `dimaster view`, `docker`, `icat` читают те же настройки.
- Если после правки что-то сломалось, удалите таблицу `limits`.

Действующие значения с пояснениями лежат комментариями в `settings/behavior.lua` после `dimaster --setup`.

## Вывод программ и буфер обмена

Защищают от программы, которая шлёт в терминал огромные данные (в том числе `cat` чужого файла или сервер по SSH).

| Ключ | По умолчанию | Минимум | Максимум | Что будет при изменении |
|---|---|---|---|---|
| `escape_string_bytes` | 16777216 (16 МБ) | 64 | без практического предела | больше — программа может занять всю память одной escape-строкой |
| `clipboard_bytes` | 1048576 (1 МБ) | 0 | без практического предела | больше — программа может положить в буфер обмена огромный текст |
| `shell_text_bytes` | 4096 | 16 | без практического предела | больше — длинные заголовки и пути от программ занимают память |
| `hyperlinks` | 4096 | 1 | 65535 | больше — растёт память под ссылки |
| `hyperlink_bytes` | 2048 | 16 | 1048576 | больше — программа может подсунуть огромный адрес |
| `hyperlink_sweep_pause` | 256 | 4 | без практического предела | меньше — частая очистка ссылок тормозит вывод |
| `keyboard_stack` | 16 | 1 | 100000 | больше — программы копят режимы клавиатуры |
| `reply_backlog_bytes` | 1048576 (1 МБ) | 1024 | без практического предела | больше — ответы программе, которая их не читает, копятся в памяти |
| `regex_bytes` | 1048576 (1 МБ) | 1024 | без практического предела | больше — сложный поиск может занять всю память |

## Что нельзя изменить из Lua

- Коды и форматы протоколов (клавиши Kitty, таблицы символов, PNG, Sixel): программы перестали бы понимать терминал.
- Число параметров одной escape-последовательности и размер атласа глифов: заданы при сборке.
- Формулы встроенных рисованных фонов. Свой фон — картинкой или в [`draw.lua`](../interface/draw.md).
