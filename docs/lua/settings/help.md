# Приветствие и советы при ошибке: `help`

[← к оглавлению](../README.md)

Таблица управляет тремя вещами: строками после мастера первого запуска, подсказкой исправления опечатки при наборе и советом после упавшей команды. Пишите её в `local.lua`.

## Совет после упавшей команды

Совет показывается плашкой в углу окна. Сам терминал ничего не выполняет. Место и вид плашки — [`ui.notice`](../interface/ui.md).

Нужна [интеграция с shell](behavior.md): без меток команд терминал не знает, что команда завершилась и с каким кодом. На удалённом сервере без интеграции советов нет.

### Как выбирается совет

Берётся первое слово команды (программа).

**Сначала проверка «команда не найдена».** Все условия вместе:

1. код возврата `127`;
2. в первом слове нет `/` и `=` (это не путь и не присваивание);
3. это слово встречается в выводе (так алиас или скрипт, упавший внутри, не принимается за отсутствующую программу).

Если такой программы действительно нет:

- есть похожее имя (опечатка, отличие не больше двух правок) — текст `similar`;
- похожего нет — текст `missing`, а под ним команда поиска из `managers` для первого найденного менеджера пакетов.

**Иначе проверка прав.** Совета нет, если код `0` или программа указана в `skip`.

- код `126` и в имени есть `/` — текст `chmod`;
- в выводе есть любая фраза из `denied` (регистр не важен) — текст `sudo`.

| Что набрали | Что напечатала программа | Совет |
|---|---|---|
| `touch /etc/x` | `Permission denied` | `Ctrl+Shift+S` добавит `sudo` |
| `./run.sh` без права на запуск | код 126 | `chmod +x ./run.sh` |
| `gti status` | `command not found` | возможно, `git` |
| `htop`, не установлен | `command not found` | не установлена, `pacman -Ss htop` |
| `ssh host` | `Permission denied (publickey)` | нет: `ssh` в `skip` |

## Ключи

| Ключ | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `enabled` | да/нет | `true` | показывать советы после ошибки |
| `duration` | мс, 200–60000 | `8000` | сколько висит плашка |
| `welcome` | список строк | приветствие и 4 клавиши | печатается после мастера; `{}` отключает |
| `typo` | строка с `{fix}` | `"  ➜ {fix}   Ctrl+→"` | призрачная подсказка опечатки; `""` отключает |
| `sudo` | строка | `"Нет прав: Ctrl+Shift+S добавит sudo"` | совет про права |
| `chmod` | строка с `{file}` | `"Файл не запускается: chmod +x {file}"` | файл не исполняемый |
| `missing` | строка с `{name}` | `"Программа {name} не установлена"` | программы нет |
| `similar` | строка с `{fix}` | `"Возможно, вы имели в виду: {fix}"` | похоже на опечатку |
| `denied` | список строк | фразы на английском и русском | признаки нехватки прав |
| `skip` | список строк | `sudo`, `doas`, `ssh`, `scp`, `sftp`, `git` | кому `sudo` не поможет |
| `managers` | список пар | `pacman`, `apt`, `dnf`, `zypper` | `{ "программа", "команда поиска" }` |

Стандартные тексты переводятся на язык терминала. Свой текст показывается как есть. Пустая строка в `sudo`, `chmod`, `missing`, `similar` отключает только этот совет.

Списки **заменяются целиком**, а не дополняются: чтобы добавить одну фразу, перечислите и прежние. Стандартные `denied`: `"permission denied"`, `"operation not permitted"`, `"are you root"`, `"unless you are root"`, `"отказано в доступе"`, `"операция не позволена"`.

## Примеры

```lua
-- отключить советы, оставить подсказку опечатки
return { help = { enabled = false } }
```

```lua
-- свои тексты и дольше на экране
return {
  help = {
    duration = 15000,
    sudo = "Не хватает прав. Ctrl+Shift+S",
    similar = "Может быть, {fix}?",
  },
}
```

```lua
-- Alpine и Nix: свои команды поиска; первый найденный менеджер выигрывает
return {
  help = { managers = { { "apk", "apk search" }, { "nix", "nix search nixpkgs" } } },
}
```

```lua
-- своё приветствие или без него
return { help = { welcome = { "Привет!", "  Ctrl+Shift+P  все команды" } } }
```

`Ctrl+Shift+S` в тексте — обычные буквы. Если переназначили действие `sudo_fix`, поправьте и строку `sudo`. Клавиши принятия исправления задаются в [`tuning.suggest_word`](tuning.md).

Приветствие печатается после мастера и берётся из только что записанных настроек. При самом первом запуске своих настроек обычно ещё нет, поэтому строки стандартные; своё приветствие из `local.lua` вы увидите после повторного `dimaster --setup`.
