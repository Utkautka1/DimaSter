# Списки: SSH, сниппеты, Docker

[← к оглавлению](../README.md)

Все три списка устроены одинаково: набирайте часть названия, выбирайте стрелками (или `Ctrl+J`, `Ctrl+K`), `Esc` закрывает.

**Что значит «выполнить».** Команда выполняется сама, только когда вы стоите у пустого приглашения shell (нужна интеграция). Если строка не пуста, идёт другая программа или интеграции нет, команда лишь вставляется. В полноэкранных программах списки не открываются.

## SSH: `Ctrl+Shift+E`

Серверы берутся из `~/.ssh/config` и файлов, подключённых через `Include`. Шаблоны (`Host *`) не показываются.

| Клавиша | Действие |
|---|---|
| Enter | `ssh <сервер>` |
| Shift+Enter | только вставить команду |

## Сниппеты: `Ctrl+Shift+I`

```lua
return {
  snippets = {
    { name = "Логи контейнера", command = "docker logs -f {{контейнер}}" },
    { name = "Большие файлы", command = "du -ah . | sort -rh | head -20" },
    { name = "Коммит", command = "git commit -m '{{сообщение}}'" },
  },
}
```

Поля пишутся в двойных скобках: `{{имя}}`; одиночные скобки (`awk '{print $1}'`) не трогаются. Список спрашивает значения по очереди, одинаковые имена заполняются разом. Готовая команда **вставляется в строку, а не выполняется**: проверьте и нажмите Enter. Значения подставляются как есть, кавычки ставьте в самом сниппете.

Команда сниппета — одна строка. Список `snippets` из более позднего слоя заменяет прежний целиком.

## Docker: `Ctrl+Shift+D`

Все контейнеры; `▶` запущен, `■` остановлен.

| Клавиша | Действие |
|---|---|
| Enter | запущенный: `docker exec -it … sh`; остановленный: `docker start …` |
| Shift+Enter | то же, но только вставить |
| Ctrl+L | `docker logs -f --tail 200 …` |
| Ctrl+S | остановить или запустить |
| Ctrl+R | перезапустить |

Список снимается в момент открытия. Если Docker не отвечает две секунды, окно покажет это и не будет ждать дальше.

## Свои клавиши

Действия: `ssh_hosts`, `snippets`, `docker`.

```lua
return { keys = { { key = "ctrl+shift+k", action = "docker" } } }
```
