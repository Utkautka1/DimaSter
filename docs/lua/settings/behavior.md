# Поведение

[← к оглавлению](../README.md)

| Ключ | Тип и значения | По умолчанию |
|---|---|---|
| `scrollback` | строк истории, до 1 000 000 | `10000` |
| `scrollbar` | полоса прокрутки с метками | `true` |
| `smart` | см. [Умная оболочка](../settings/behavior.md) | включено |
| `widgets` | см. [Виджеты](../interface/statusbar.md) | строка статуса включена |
| `env` | переменные окружения shell: `{ ИМЯ = "значение" }` | `{}` |
| `shell` | команда списком: `{ "/usr/bin/fish", "-l" }` | `$SHELL` |
| `term` | значение `TERM`; свой — `"xterm-dimaster"` | `"xterm-256color"` |
| `rtl` | переставлять иврит и арабский | `true` |
| `images_scroll` | картинки уходят в историю с текстом | `true` |
| `copy_on_select` | `"primary"`, `"clipboard"`, `"off"` | `"primary"` |
| `scroll_multiplier` | строк на щелчок колеса, 0.1–50 | `3` |
| `clipboard_write` | программы пишут в буфер обмена (OSC 52) | `true` |
| `clipboard_paste_protection` | предупреждать перед вставкой опасного текста | `true` |
| `mouse_hide_while_typing` | скрывать указатель мыши при наборе текста | `false` |
| `confirm_close` | спрашивать подтверждение перед закрытием окна | `false` |
| `remote_control` | разрешить `dimaster ctl` (применяется при запуске) | `true` |
| `session` | `{ restore = false, history_lines = 2000 }` | выключено |

Читать буфер обмена программам нельзя ни при каких настройках. `session.restore` записывает вывод терминала на диск.

`language`: `"auto"`, `"ru"`, `"en"` или свой код — см. [Языки](../lang/lang.md).

## Умная оболочка

DimaSter сам подключает метки команд к zsh, bash и fish, не меняя ваши dotfiles. Это работает, когда запускается сам shell без аргументов (не для `-e` и не для shell с флагами). На удалённых серверах метки не появляются.

```lua
return {
  scrollbar = true,          -- полоса прокрутки: синие метки команд, красные ошибки, жёлтые находки
  smart = {
    integration = true,
    startup_fetch = true,    -- автоматически запускать `dimaster fetch` при открытии shell
    syntax_highlight = true, -- встроенная подсветка вводимых команд (без плагинов shell)
    color_ls = true,         -- цветной `ls` и `LS_COLORS` из коробки
    autosuggest = true,      -- призрачные автоподсказки команд из истории (Right / Ctrl+Right)
    autopair = true,         -- умное автозакрытие скобок и кавычек () [] {} "" ''
    not_found = true,        -- «команда не найдена» на языке терминала (zsh, bash, fish)
    ok = "➜ OK",             -- под успешной командой без вывода; "" отключает
    empty = "∅ Ничего не найдено",
    errors = true,           -- код ошибки, если команда ничего не напечатала
    search_tools = { "grep", "rg", "find", "fd", "ls", "locate" },
    long_command = 10,       -- секунды; 0 отключает
    glow = true,             -- пульсация рамки, если окно не в фокусе
    glow_color = "#7aa2f7",
    notify = true,           -- уведомление рабочего стола
    double_alt_sudo = false, -- осторожно: может срабатывать от Alt+Tab
  },
}
```

`empty` показывается, когда программа из `search_tools` ничего не вывела и вернула 0 или 1 (так `grep` сообщает об отсутствии совпадений).

История команд (Ctrl+Shift+H) хранится в памяти окна: до 100 команд и 200 строк вывода каждой, на диск не пишется. `j`/`k` выбор, Enter вставляет команду, `y` копирует вывод.

В окне настроек есть `window.background_dir`: фон выбирается случайно из картинок каталога при запуске и перечитывании настроек.

## Приглашение shell и `env`

Приглашение (имя, каталог, версии, время перед `➜`) рисует не терминал, а программа в shell — например, `starship`; её тексты настраиваются в `~/.config/starship.toml`. Чтобы у DimaSter было своё приглашение, не затрагивая другие терминалы:

```lua
-- local.lua
return { env = { STARSHIP_CONFIG = "~/.config/dimaster/starship.toml" } }
```

`env` задаёт любые переменные окружения для shell; `~/` раскрывается. Действует на новые окна.
