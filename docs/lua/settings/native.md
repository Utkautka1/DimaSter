# Удобства shell без плагинов: `native`

[← к оглавлению](../README.md)

Всё это делает сам терминал, поэтому плагины zsh не нужны. Работает в приглашении, когда есть [интеграция с shell](behavior.md). На удалённом сервере без интеграции клавиши достаются shell.

## Поиск по истории стрелками

Наберите начало команды, например `git`, и нажимайте `↑`: листаются только команды с этим началом, от новых к старым. `↓` возвращает назад, в конце — к набранному. На пустой строке стрелки работают как обычно в shell.

## Меню по `Tab`

| Где курсор | Что предлагается |
|---|---|
| первое слово | команды из `$PATH`, встроенные, ваши алиасы и сокращения |
| слово с `-` | флаги из `man` этой команды |
| аргумент команды из `path_commands` или слово с `/` | файлы и каталоги (`cd` — только каталоги) |
| всё остальное | `Tab` получает shell, его дополнение работает как раньше |

Один вариант вставляется сразу. Несколько — открывается меню: печатайте для нечёткого поиска, стрелки выбирают, `Enter` вставляет, `Esc` закрывает. Строки с кавычками и `\\` дополняет shell. Программа ради флагов не запускается.

## Сокращения

```lua
return { native = { abbreviations = { gs = "git status", dc = "docker compose" } } }
```

Наберите `gs` и пробел — строка станет `git status `. Разворачивается только первое слово, и вы видите полную команду до запуска.

## Алиасы для всех shell

```lua
return { native = { aliases = { ll = "ls -la", g = "git" } } }
```

Одна таблица для zsh, bash и fish. Добавляются после ваших файлов shell и заменяют одноимённые алиасы. Действуют в новых окнах. Имя: латиница, цифры, `.`, `_`, `-`; значение — одна строка.

Переменные окружения задаются ключом [`env`](behavior.md): `env = { EDITOR = "nvim" }`.

## Ключи

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `history_search` | `true` | поиск по истории стрелками |
| `shell_history` | `true` | искать и в истории shell (`~/.zsh_history` или `$HISTFILE`, `~/.bash_history`, история fish); файлы только читаются. История Atuin отдельно не читается |
| `history_back`, `history_forward` | `{ "up" }`, `{ "down" }` | клавиши листания; формат как в [`tuning`](tuning.md) |
| `complete` | `true` | меню дополнения |
| `complete_keys` | `{ "tab" }` | клавиши меню |
| `man_flags` | `true` | флаги из `man` |
| `path_commands` | `cd`, `ls`, `cat`, `vim`, `cp`, `mv`, `rm` и другие | кому дополнять файлы; список заменяется целиком |
| `abbreviations` | пусто | сокращения |
| `aliases` | пусто | алиасы |

Отключить всё и вернуть поведение shell:

```lua
return { native = { history_search = false, complete = false } }
```

Если стоят `zsh-history-substring-search` или `fzf-tab`, отключите здесь соответствующую функцию: иначе первым отвечает терминал.
