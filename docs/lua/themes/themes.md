# Темы

[← к оглавлению](../README.md)

Тема — файл `themes/<имя>.lua`, возвращающий цвета:

```lua
return {
  foreground = "#cdd6f4",
  background = "#1e1e2e",
  cursor = "#f5e0dc",
  selection = "#585b70",
  selection_text = "#cdd6f4", -- необязательно
  ansi = {
    "#45475a", "#f38ba8", "#a6e3a1", "#f9e2af", "#89b4fa", "#f5c2e7", "#94e2d5", "#bac2de",
    "#585b70", "#f38ba8", "#a6e3a1", "#f9e2af", "#89b4fa", "#f5c2e7", "#94e2d5", "#a6adc8",
  },
}
```

Встроенные: `catppuccin-mocha`, `gruvbox-dark`, `nord`. Кроме того, по имени подхватываются темы Ghostty — из `~/.config/ghostty/themes` и `/usr/share/ghostty/themes`: `theme = "Catppuccin Mocha"`. Ваш файл с тем же именем важнее встроенной темы. Цвета: `#rrggbb` или `#rgb`. Отдельные цвета поверх темы задаются в `colors` теми же ключами.

Программы могут временно менять цвета (OSC 4, 10, 11, 12); сброс возвращает тему.

## Своя тема по шагам

1. Создайте `~/.config/dimaster/themes/mine.lua` с таблицей цветов, как выше.
2. В `local.lua` напишите `theme = "mine"`.
3. Правьте файл темы: изменения видны сразу.

## Порядок цветов в `ansi`

| № | Цвет | Яркий № |
|---|---|---|
| 1 | чёрный | 9 |
| 2 | красный | 10 |
| 3 | зелёный | 11 |
| 4 | жёлтый | 12 |
| 5 | синий | 13 |
| 6 | пурпурный | 14 |
| 7 | голубой | 15 |
| 8 | белый | 16 |

Эти цвета используют программы (`ls`, `git`, редакторы) и части самого терминала: подсветка команд, подсветка nano, полоска выполнения.

## Импорт из другого терминала

`dimaster --setup` переносит цвета, шрифт и отступы из Ghostty, kitty и Alacritty в `themes/imported.lua` и `settings/`.
