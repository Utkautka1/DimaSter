# Витрина скинов

[← к оглавлению](../README.md)

`Ctrl+Shift+K` (действие `skins`, в палитре «Скины: витрина цветов») открывает 50 встроенных цветовых схем и 8 стилей — всего 400 сочетаний. Конфиги править не нужно.

| Что сделать | Как |
|---|---|
| посмотреть | стрелки или колесо мыши: окно перекрашивается сразу |
| выбрать | щелчок по строке (витрина остаётся) или Enter (закроется) |
| сменить стиль | ← →, щелчок по строке «Стиль» (левее — назад, правее — вперёд) |
| найти | набирайте часть названия |
| выйти без изменений | Esc или щелчок мимо: вернётся последний сохранённый |
| вернуть цвета из настроек | пункт «Как в настройках» |

## Стили

| Стиль | Вид | Фон |
|---|---|---|
| Стекло | прозрачность с размытием, пульсирующая черта, скруглённый бар | мягкие пятна |
| Неон | блок с хвостом, острые «стрелки» в баре | сетка и солнце |
| Минимализм | без анимаций, подчёркивание, плоский бар | нет |
| Ретро | своя рамка, мигающий блок, скобки в баре | развёртка |
| macOS | круглые кнопки слева, бар сверху | волны |
| Закат | пульсирующая черта с хвостом | солнце и горы |
| Ночной город | полупрозрачный блок | небоскрёбы и звёзды |
| Лепестки | подчёркивание с хвостом, бар сверху | лепестки |

Фоны рисуются самим терминалом из цветов палитры, файлов картинок нет. Стиль меняет окно, отступы, курсор, панели, заголовок и строку статуса; пока он выбран, `statusbar.lua` и ваши `window.background_image` не используются. «Как в настройках» всё возвращает. Приглашение starship стиль не меняет.

Выбор хранится в `~/.local/share/dimaster/` (`skin` и `style`). Палитра накладывается поверх `theme` и `colors`. То, что ставят плагины через `dimaster.set`, важнее скина. Другие открытые окна перекрасятся после перезагрузки настроек (`Ctrl+Shift+,`), новые — сразу.

Палитра без стиля меняет только цвета терминала и панелей. Цвета, заданные вручную в `ui.lua` и `starship.toml`, остаются как есть; `fetch` берёт цвета из палитры.

Палитры взяты из набора [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) (лицензия MIT).
