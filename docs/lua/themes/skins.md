# Витрина скинов

[← к оглавлению](../README.md)

`Ctrl+Shift+K` (действие `skins`, в палитре «Скины: витрина цветов») открывает 50 встроенных цветовых схем и 8 стилей — всего 400 сочетаний. Конфиги править не нужно.

| Что сделать | Как |
|---|---|
| посмотреть | стрелки или колесо мыши: окно перекрашивается сразу |
| выбрать | щелчок по строке (витрина остаётся) или Enter (закроется) |
| сменить стиль | ← →, щелчок по строке «Стиль» (левее — назад, правее — вперёд) |
| найти | набирайте часть названия |
| выйти без изменений | Esc или щелчок мимо: вернётся последний сохранённый |
| вернуть цвета из настроек | пункт «Как в настройках» |

## Стили

| Стиль | Бар и элементы | Приглашение | Фон |
|---|---|---|---|
| Стекло | снизу капсулой: режим и путь · ветка · часы | две строки с «таблетками» | пятна |
| Неон | сверху: режим, машина, путь · ветка, язык · CPU, память, часы; полоса прокрутки | в одну строку, стрелки | сетка и солнце |
| Минимализм | ничего: ни бара, ни прокрутки | каталог и `❯` | нет |
| Ретро | две строки снизу: пользователь и дата; путь, ветка, процесс, CPU, память; своя рамка | `user@host:путь$` | развёртка |
| macOS | без бара; рамка с кнопками слева и миникарта | `host каталог git:(ветка) %` | волны |
| Закат | островок по центру: дата, ветка, время | две строки | горы |
| Ночной город | две строки мониторинга с Docker, монитор в углу, миникарта | «дерево» с временем и длительностью | небоскрёбы |
| Лепестки | сверху по центру: путь и время | `✿ путь ❀ ветка` | лепестки |

Фоны рисуются самим терминалом из цветов палитры, файлов картинок нет. Стиль меняет окно, отступы, курсор, панели, заголовок и строку статуса; пока он выбран, `statusbar.lua` и ваши `window.background_image` не используются. «Как в настройках» всё возвращает. У каждого стиля своё приглашение starship, оно появляется со следующей строки; ваш `starship.toml` на это время не используется.

Выбор хранится в `~/.local/share/dimaster/` (`skin` и `style`). Палитра накладывается поверх `theme` и `colors`. То, что ставят плагины через `dimaster.set`, важнее скина. Другие открытые окна перекрасятся после перезагрузки настроек (`Ctrl+Shift+,`), новые — сразу.

Палитра без стиля меняет только цвета терминала и панелей. Цвета, заданные вручную в `ui.lua`, остаются как есть; `fetch` берёт цвета из палитры.

## Приглашение starship

Shell получает `STARSHIP_CONFIG`, указывающий на копию `~/.local/share/dimaster/starship.toml`. Терминал заменяет в ней все цвета `#rrggbb` на близкие по роли цвета палитры, а ваш файл не меняет. Править приглашение продолжайте в своём файле; изменения попадут в копию после `Ctrl+Shift+,`. Окна, открытые до обновления DimaSter, читают прежний файл.

Палитры взяты из набора [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) (лицензия MIT).
