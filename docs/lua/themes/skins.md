# Витрина скинов

[← к оглавлению](../README.md)

`Ctrl+Shift+K` (действие `skins`, в палитре «Скины: витрина цветов») открывает 50 встроенных цветовых схем. Конфиги править не нужно.

| Что сделать | Как |
|---|---|
| посмотреть | стрелки или колесо мыши: окно перекрашивается сразу |
| выбрать | щелчок по строке (витрина остаётся) или Enter (закроется) |
| найти | набирайте часть названия |
| выйти без изменений | Esc или щелчок мимо: вернётся последний сохранённый |
| вернуть цвета из настроек | пункт «Как в настройках» |

Выбор хранится в `~/.local/share/dimaster/skin` и накладывается поверх `theme` и `colors`. То, что ставят плагины через `dimaster.set`, важнее скина. Другие открытые окна перекрасятся после перезагрузки настроек (`Ctrl+Shift+,`), новые — сразу.

Скин меняет только цвета терминала и панелей. Цвета, заданные вручную в `statusbar.lua`, `ui.lua`, `starship.toml` и `fetch.lua`, остаются как есть.

Палитры взяты из набора [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) (лицензия MIT).
