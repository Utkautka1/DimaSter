# С чего начать

[← к оглавлению](README.md)

## Первые пять минут

1. Откройте `~/.config/dimaster/local.lua`. Это ваш файл: терминал его не перезаписывает, и он перекрывает всё остальное.
2. Напишите в нём таблицу настроек и сохраните. Изменения применяются сразу, перезапуск не нужен.
3. Если в заголовке окна появилось «ошибка в init.lua», действуют прежние настройки. Текст ошибки печатается в stderr (запустите `dimaster` из другого терминала).

```lua
return {
  language = "ru",
  theme = "catppuccin-mocha",
  font = { family = "JetBrainsMono Nerd Font", size = 12 },
  window = { opacity = 0.85, blur = true },
  cursor = { shape = "bar", pulse = true },
}
```

## Сколько Lua нужно знать

| Конструкция | Пример | Что значит |
|---|---|---|
| таблица | `{ size = 12, ligatures = true }` | набор «ключ = значение» |
| список | `{ "/usr/bin/fish", "-l" }` | значения по порядку |
| строка | `"#1e1e2e"`, `"ctrl+shift"` | в кавычках |
| комментарий | `-- заметка` | не выполняется |
| условие | `dimaster.ssh and 10 or 12` | «если … то … иначе» |

Между элементами таблицы нужна запятая. Лишняя запятая после последнего элемента не ошибка.

## Что в каком файле менять

| Хочу изменить | Где |
|---|---|
| шрифт, тему, окно, клавиши, поведение | `local.lua` |
| заголовок, палитру, панели, плашку копирования | `ui.lua` |
| строку статуса | `statusbar.lua` |
| фигуры и графики поверх окна | `draw.lua` |
| вывод `dimaster fetch` | `fetch.lua` |
| свои команды и реакции на события | `plugins/*.lua` |
