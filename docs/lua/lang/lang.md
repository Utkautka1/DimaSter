# Языки

[← к оглавлению](../README.md)

```lua
return { language = "en" } -- "auto" (по локали системы), "ru", "en" или свой код
```

Переводятся тексты интерфейса, подсказки под командами, палитра, уведомления, сообщения команд `dimaster` и строки `fetch`. Записи лога и комментарии в созданных файлах настроек остаются русскими. «Команда не найдена» в zsh, bash и fish тоже выводится на языке терминала (`smart.not_found = false` отключает; ваш собственный обработчик не заменяется). Остальные сообщения программ задаёт локаль системы: её можно сменить для shell через `env = { LC_MESSAGES = "ru_RU.UTF-8" }`, если эта локаль установлена.

## Свой язык

Файл `lang/<код>.lua` возвращает пары «русская строка — перевод»; непереведённое показывается по-английски:

```lua
-- lang/de.lua, включается language = "de"
return {
  ["Копировать"] = "Kopieren",
  ["Вставить"] = "Einfügen",
  ["команда не найдена"] = "Befehl nicht gefunden",
}
```

Все строки с английским переводом — в `crates/dimaster-i18n/src/en.tsv`. Тем же файлом `lang/ru.lua` или `lang/en.lua` можно переписать отдельные фразы.

## Как проверить свой перевод

1. Создайте `lang/de.lua` с несколькими строками.
2. Укажите `language = "de"` в `local.lua`.
3. Откройте палитру: переведённые строки показываются по-вашему, остальные — по-английски.

Подстановки в фигурных скобках (`{count}`, `{path}`) переносите в перевод без изменений.
