# Языки

[← к оглавлению](../README.md)

```lua
return { language = "en" } -- "auto" (по локали системы), "ru", "en" или свой код
```

Переводятся тексты интерфейса, подсказки под командами, палитра, уведомления, сообщения команд `dimaster` и строки `fetch`. Записи лога и комментарии в созданных файлах настроек остаются русскими. Сообщения shell и программ (например, `zsh: command not found`) задаёт локаль системы, а не терминал.

## Свой язык

Файл `lang/<код>.lua` возвращает пары «русская строка — перевод»; непереведённое показывается по-английски:

```lua
-- lang/de.lua, включается language = "de"
return {
  ["Копировать"] = "Kopieren",
  ["Вставить"] = "Einfügen",
  ["команда не найдена"] = "Befehl nicht gefunden",
}
```

Все строки с английским переводом — в `crates/dimaster-i18n/src/en.tsv`. Тем же файлом `lang/ru.lua` или `lang/en.lua` можно переписать отдельные фразы.
